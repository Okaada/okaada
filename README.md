- ☁️ Before becoming Head, I was the Senior DevOps who **led the company's migration from GCP to AWS**.

### How I build platforms

| Principle | In practice |
|---|---|
| **Everything as code** | Terraform for infrastructure, GitHub Actions for delivery — no click-ops in production |
| **Security by default** | Least-privilege IAM, short-lived credentials in CI, hardened container images, secrets out of repos |
| **Cost is an engineering metric** | Tagging, ownership and untagged-resource hunting are part of the platform, not an afterthought |
| **Boring, observable systems** | Managed services first (ECS Fargate, RDS, Lambda), with metrics and alerts before the first incident |
